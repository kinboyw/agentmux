# 08. Operational Scenarios

## Purpose

Communicate the user story: one person manages long-lived agent sessions across
multiple machines and devices.

## Recommended Placement

- Landing page hero/supporting visual
- README overview
- Product narrative docs

## Aspect Ratio

16:9, 1920x1080.

## Positive Prompt

Editorial product illustration showing AgentMux in real usage. A developer has a laptop open to a browser-based multi-pane terminal workspace. Around the scene are three remote worker machines represented as clean device/server silhouettes: home workstation, cloud VM, lab machine. Thin WSS lines route from all workers to a central small Hub node, then to the browser control surface. Each worker has tiny tmux session chips, not detailed text. The scene should feel practical and calm: remote work, multiple devices, long-lived coding agents, no inbound worker ports. Use dark graphite background, subtle green connection lines, blue browser highlights, amber signal token icon in the corner. Avoid photorealistic faces; keep people abstract or omit them.

## Negative Prompt

Stock photo office, smiling people pointing at screens, cartoon robots, cyberpunk hacker room, excessive neon, unreadable UI text, random code waterfalls, brand logos, fantasy cloud icons.

## Review Checklist

- Multi-device/multi-worker story is immediately visible.
- Browser Control is the main user surface.
- Hub is present but not dominant.
- Long-lived tmux/agent sessions are implied by chips/panes.
- Image works as a product page visual, not just an architecture diagram.
