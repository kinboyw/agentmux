# 04. Web Control Workspace

## Purpose

Show the product surface: browser-based multi-pane terminal control with session
metadata outside the terminal buffer.

## Recommended Placement

- Landing page feature section
- Web Control documentation
- README screenshot/illustration slot

## Aspect Ratio

16:9, 1920x1080.

## Positive Prompt

Polished product UI illustration of the AgentMux Web Control workspace. A modern browser window on a dark graphite background. Inside the app: a compact left sidebar listing workers and sessions, a top status strip, and a main area split into three resizable terminal panes. Each terminal pane has a narrow header with session names like "local/codex", "gpu/claude", "server/shell". Show subtle drag handles between panes and terminal content as abstract readable blocks, not real logs. Use restrained green focus outline on the active pane, muted borders, small icons, dense developer-tool layout. The image should communicate efficient multi-session control, not a marketing dashboard. Keep UI text minimal and legible.

## Negative Prompt

Huge hero dashboard with decorative cards, bright gradients, fake analytics charts, illegible code dumps, browser chrome clutter, cartoon agents, overlapping text, oversized rounded cards, mobile-first layout.

## Review Checklist

- Multi-pane split layout is clear.
- Sidebar and terminal pane headers are compact.
- Session identity is outside terminal content.
- UI feels like an operational tool for repeated use.
